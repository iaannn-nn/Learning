# Software application types
- Business software manages services such as accounting.
- Embedded software resides in and controls consumer products such as microwaves.
- Engineering and scientific software performs intensive calculations such as computer simulations.
- Expert system software solves complex problems such as medical diagnosis.
- Personal software serves individual users with tasks such as word processing and gaming.
- Realtime software monitors and analyzes events within milliseconds such as equipment control
- System software serves other programs such as operating systems
# Systems 
- A system is composed of connected elements, working together to achieve an objective. 
- A complex system are composed of many subsystems.
