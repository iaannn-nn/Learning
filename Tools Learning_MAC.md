# Tools Learning_MAC

## From Claude: 
Here are the Mac tips that make the biggest difference, especially if you're coming from Windows:

**Keyboard basics**

- **Cmd (⌘)** does what Ctrl does on Windows: Cmd+C/V/X/Z, Cmd+S, Cmd+F.
- **Cmd+Space** opens Spotlight. Use it to launch apps, find files, do quick math, or convert currencies. It's the fastest way to do almost anything.
- **Cmd+Tab** switches apps. **Cmd+`** switches between windows of the same app.
- **Cmd+Q** quits an app completely. Clicking the red ✕ only closes the window, and the app keeps running.
- **Cmd+W** closes the current tab or window.
- **Cmd+Shift+4** takes a screenshot of an area. Press Space afterward to capture a single window. **Cmd+Shift+5** gives you all screenshot and screen-recording options.
- **Delete** works like Backspace. **Fn+Delete** deletes forward.

**Trackpad gestures**

- Two-finger tap = right-click.
- Three-finger swipe up = Mission Control, which shows all open windows.
- Swipe left or right with three or four fingers to switch between full-screen apps and desktops.
- Pinch with thumb and three fingers to show the desktop.
- Turn on **Tap to click** and **three-finger drag** in System Settings → Trackpad / Accessibility → Pointer Control. They save a lot of effort.

**Finder (file manager)**
- **Space** on any file gives an instant preview (Quick Look). It works for PDFs, images, and Word files.
- **Cmd+Shift+.** shows hidden files.
- **Enter** renames a file. **Cmd+O** opens it.
- **Cmd+Delete** moves a file to Trash.
- Turn on View → Show Path Bar and Show Status Bar so you always know where you are.

**Window management**
- macOS has basic window snapping now: hover over the green button, or drag a window to the edge of the screen.
- For better control, install **Rectangle** (free). It gives you keyboard shortcuts to snap windows to halves or quarters, which is great for work with multiple screens.

**Useful habits**
- Use **Stage Manager** or multiple **Desktops** (Spaces) to separate work from personal stuff.
- Set up **Hot Corners** in System Settings → Desktop & Dock. For example, move the mouse to a corner to lock the screen.
- **Cmd+Ctrl+Q** locks your Mac instantly.
- Typing Vietnamese: add the Vietnamese input under Keyboard → Input Sources, or install **EVKey** or **OpenKey** for better Telex typing.

**Free apps worth installing**

- **Rectangle** for window snapping
- **Raycast**, a more powerful Spotlight with a clipboard history
- **AltTab**, if you prefer Windows-style window switching
- **The Unarchiver**, to open .rar and .7z files
